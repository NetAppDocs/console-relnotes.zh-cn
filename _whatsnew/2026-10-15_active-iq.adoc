=== Value Insights 中的 E-Series 和 StorageGRID 支持

Value Insights 现在包括 ONTAP、E-Series 和 StorageGRID 系统的健康、风险、安全风险和生命周期总计。您可以按平台筛选控制面板，以查看特定于平台的详细信息。交付和预计节省的费用仅适用于 ONTAP 系统。
